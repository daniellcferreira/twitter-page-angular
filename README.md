## Descrição

Este projeto é uma aplicação front-end construída com Angular e estilizada utilizando Tailwind CSS. 
Ele simula uma interface de rede social similar ao Twitter, focando na componentização, reutilização de código e uso de boas práticas com Angular.

A estrutura é baseada em componentes funcionais e serviços para separação de responsabilidades. 
A aplicação não possui backend e os dados são armazenados apenas em memória, simulando o comportamento de uma timeline de publicações.

## Funcionalidades

- Exibição de uma lista de tweets simulados em tela
- Criação de novos posts via componente de input
- Visualização de cada post em um componente separado
- Utilização de avatars e nomes simulados para cada tweet
- Responsividade da interface com utilitários Tailwind CSS
- Separação clara entre componentes de layout, lógica e estilo
- Atualização dinâmica da lista de tweets após novo post
- Organização modular por componentes (header, footer, tweet, etc.)
- Utilização de serviço Angular para gerenciamento dos dados dos tweets
- Código limpo e estruturado para fácil manutenção e expansão futura

## Tecnologias abordadas

- **Angular**: Framework principal para estruturação da aplicação SPA
- **TypeScript**: Linguagem utilizada com Angular para garantir segurança de tipos
- **Tailwind CSS**: Framework utilitário para estilização rápida e responsiva
- **HTML5**: Linguagem de marcação para estrutura da interface
- **CSS3**: Estilização complementar quando necessário

Cada tecnologia foi escolhida para proporcionar uma arquitetura moderna, escalável e de fácil manutenção, com foco no desenvolvimento front-end moderno baseado em componentes.
